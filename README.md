# Borozdov Ticker

A theme from the Borozdov collection. Two faces — dark **Afterhours**, a nocturnal trading
terminal, and light **Premarket**, the same desk before the open. Matte black, luminous
white type, glowing ghost pills and three signal colours for what moves.

![Borozdov Ticker in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/ticker/main/screenshots/dark.png)

![Borozdov Ticker in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/ticker/main/screenshots/light.png)

## Principles

- **Luminous type on matte black.** The canvas is a deep matte black and the type is the
  brightest thing on screen: bold headlines compressed tighter as they grow, plain text at
  400, numbers in tables and the status bar set in tabular figures.
- **Colour as signal, not decoration.** Ember marks what you tick, the caret and the
  highlighter; signal blue marks links and the open file; growth green marks tags. Nothing
  else is chromatic.
- **A button that glows.** The main button has no fill colour at all — a ghost pill with a
  soft white halo. Everything interactive is a pill.
- **Cards that float.** Callouts, embeds and panels are charcoal with 16px corners, lifted
  off the canvas by a heavy black halo.

## Features

- Dark and light modes, following Settings → Appearance → Base color scheme
- Tags as status badges: growth-green pill outlines with small capital labels
- Table headers in small tracked capitals; figures line up in columns
- The open file in the sidebar carries a signal-blue line
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No embedded fonts, so the theme stays around 12 KB
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Ticker**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/ticker/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Ticker/`, then choose Borozdov Ticker under
Settings → Appearance → Themes.
